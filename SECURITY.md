# Security policy

## Supported versions

We fix security problems on `main` and in the latest release. We do not
patch older releases.

## Report a vulnerability

Do not report a security problem in a public issue, pull request or
discussion. Use GitHub's private vulnerability reporting:

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem, the affected app or package, the steps to reproduce
   it, and its impact.

Only you and the maintainers can see the report. We reply in the same
advisory and tell you when a fix is available. Do not include real
credentials or other people's data in the report.
